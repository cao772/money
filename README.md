# Money — AI Venture Lab

A local-first framework for AI-assisted, low-cost commercial experiments. The goal is verifiable income, not the number of ideas or lines of code.

This public repository contains only generic software, synthetic fixtures and engineering instructions. Keep actual opportunity research, private task payloads, customer data, receipts, credentials and financial records in an authorized private workspace or an ignored local database. Never commit company/customer assets or secrets.

Default: no new cash spending, no public release, no third-party account actions, no contracts or payment changes without explicit owner approval. Use real evidence; never fabricate income or platform results.

See `AGENTS.md` and `docs/START.md` on the implementation branch when available.
